    rotateStakedBalances

    • rotateStakedBalances(
          oldConsensus: string,
          newConsensus: string,
          height: number,
      ): Promise<void>

      Migrates a validator's live delegations from an old consensus address to a new one after a consensus-key rotation. For each delegator with a non-zero delegation under the old address, at the rotation height, we write a zeroed row under the old address and an equal row under the new address so the running balance follows the validator's new consensus key.

      • oldConsensus: string
      • newConsensus: string
      • height: number

    tokensToSharesForDelegation

    • tokensToSharesForDelegation(
          amount: bigint,
          validator: string,
          height: number,
      ): Promise<BigNumber>

      Shares issued for amount tokens at the validator's current exchange rate. Uses the in-memory cache, then the voting-power table, and finally a 1:1 rate, which is exact for a validator that has never been slashed. A delegation is never dropped because the validator happened to be missing from the cache.

      Parameters

      • amount: bigint
      • validator: string
      • height: number
