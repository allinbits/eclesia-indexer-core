    Class CosmosAdapter

    Chain adapter for Cosmos SDK chains running CometBFT 0.34, 0.37 or 0.38. Fetches blocks and results through cosmjs, plus the complete validator set in full mode, and decomposes each block into the events the Cosmos modules listen to: block, begin_block, tx_events, tx_memo, one event per message type URL (authz MsgExec unwrapped), and end_block.
