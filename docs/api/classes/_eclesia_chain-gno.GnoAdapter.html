    Class GnoAdapter

    Chain adapter for gno.land and other Tendermint2 chains. Fetches blocks and results through tm2-rpc, plus the validator set in full mode, and decomposes each block into block, begin_block, one tx per transaction, one event per decoded message (named after its amino type URL: /bank.MsgSend, /vm.m_call, /vm.m_addpkg, /vm.m_run) and end_block.

    tm2-rpc has no block subscription, so the engine polls the node for new heights.
